# MVP scope and judge-facing claims

## Demonstrated

- Working resident selection and custom fictional profile
- Curated multi-need service matching
- Optional real OpenAI API explanation through a local Python backend
- Structured six-step Rent Supplement intake and saved action tracker
- Geographic basemap, community selection and synthetic analytical overlays
- On-demand public-data pipeline, sync status, citation-aware data inspector, scenario tools
- Partner and Government analytics user interfaces

## Distinguish carefully

- **Synthetic:** demand counts, unmet requests, service matches, gap scores, reachable/after-work hours and funding allocation.
- **Public / historical, when synced:** 2021 census DA geometry/population; Halifax Transit GTFS published schedule/stops.
- **Hand-curated:** sample service and provider references; not a comprehensive, live availability dataset.
- **Modeled:** potential pilot capacity, session costs, direct-trip heuristics; not real achieved outcomes.

## Not delivered

- Full official eligibility determination, submission of applications or booking
- Verified 45-minute walking + transit routes with transfers, live disruption data or accessible route guarantees
- Authenticated multi-device profiles, private case management, production data security
- Complete HRM or province-wide service directory
- Verified public-feed sync on every judge machine
